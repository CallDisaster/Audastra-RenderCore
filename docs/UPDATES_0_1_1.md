# 0.1.1：第三轮世界修复同步

来源冻结为 FORGE `eb35f870a2fd98719ac8a1b1b0bcf86b211c8ae6`，在共享 `944ae50`
上合并相应自有实现和回归，不搬设备、GPU 后端、Qt 或原版资源。
0.1.0 的独立已求值外部帧接口及其严格空间、版本、通道与失败清空规则保留。

| 同步范围 | 行为与来源 |
|---|---|
| MDX 解析及参考姿态 | 重复 TRS 同帧取最后键；普通 GEOA 单键常量；节点/碰撞选择元数据 |
| TRS/GEOA 采样 | 首键之前左端取末键但时间差仍基于首键；末键之后右端回首键；负跨度加当前动作长度，零跨度取左键；核心与独立参考分别保留实现 |
| 动作逆序区间 | 解析保留原动作，错误定位到被请求动作；不让一个坏动作拒绝其他动作 |
| Geoset 局部失败 | 保留主线明确的失败策略/问题报告；严模式与预览降级不混同 |
| 插件 V2 合同 | 完成帧/模型层尾部，截图绑定主场景与附加层身份；原 V2 函数前缀和能力尺寸探测保留 |
| 蒙皮输入校验 | 同模型完整切片可共享；跨模型、部分重叠、越界或更新切换模式仍拒绝 |

新增 `include/War3MapCore/RenderPluginEditorVisibility.h` 和
`RenderPluginModelLayers.h` 是 FORGE 原创同帧/附加层 C ABI 数据契约；
同名 Legacy 头只转发，未复制后端实现。其余来源历史仍见 `PROVENANCE.md`。
同步后的文件字节由 FORGE 新锁记录，旧 `MIGRATION.tsv` 是 0.1.0 历史来源，不伪装新 SHA。

原版接缝行为有 FORGE 研究和 Claude 的 `6F77AE30` 独立复核依据；
CPU 回归/图片一致只证明本次迁移没有改变已验证预览输出。
相机节点、squad、预览法线归一化等近似没有因此成为原版逐帧一致。
完整 WARP 在 FORGE 验证，独立上游只有 CPU/合同测试；游戏接线和原版 palette 未验。
