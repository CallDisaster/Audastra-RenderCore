# 无控制器静态模型的显式预览

0.1.3 为经典 MDX800 的一个受限结构增加显式预览接口。普通 `ParseMdx`、`CompileMdxModel` 和骨骼参考采样继续严格拒绝空矩阵组，不改变默认兼容结论。

调用方必须明确使用 `ParseMdxRigidStaticPreview`，再选择 `CompileMdxRigidStaticPreview` 或 `SampleMdxRigidStaticPreviewGeoset`。资格限制为六种已解析块、零节点、无轨迹控制器、每个顶点组号为零且矩阵组与矩阵索引都为空。其它控制器、未知块、截断、越界与非有限数据仍由原规则拒绝。

专用解析器拥有完整原始字节及各 geoset 的字段偏移。公开模型在编译和参考采样时会与这份密封来源重新比对，不能通过一个可写布尔值绕过资格检查。生成的每个 geoset 只有一个模型局部 identity 矩阵组，节点数仍为零；来源额外存储计入编译预算。实例位置、方向、比例与时钟仍由宿主分别提供，不能烘入静态资产。

结果必须标记 `MDX_RIGID_STATIC_PREVIEW` 和“预览近似”，并保留字段偏移、实际计数与源模型路径。本规则用于在编辑器中预览原始静态几何；原版同模型显示和游戏运行尚须各自验证，不能由 CPU 逐位对照签收。

插件 C ABI 没有改变。本次只增加进程内 MDX 来源句柄及 CPU 接口，宿主须同步完整私有上游锁并重新编译。验证覆盖严格入口、显式入口、两个实例、参考逐位对照、几何篡改与控制器拒绝；实际 x64/Win32 和模型副本结果由宿主回执记录。
